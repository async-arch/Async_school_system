### Fixed during this run

- `school.student.birth_certificate` and `previous_grade_document` had no group
  restriction. Any teacher could download a student's documents. Both are now
  `group_school_registrar`.
- The student record report referenced `enr.grade_id`, `enr.section_id` and
  `enr.status`, none of which exist on `school.enrollment`. The PDF never rendered.
  Now reads through `enr.class_id`.

### Found, not fixed

- Promotion into a class with no curriculum produces an empty subject roster
  silently. Grade 3 A had no subjects, so the promoted student arrived with none.
  Worth a warning in the promotion wizard.

## Known gaps, not bugs to file

- The `education_level` column on `school_subject` and the `date` column on
  `school_class_schedule` still exist in the database. Both fields were removed from
  the code; Odoo does not drop columns.
- Curriculum is keyed on class, not grade. A grade with three sections needs its
  curriculum entered three times. SRS section 7.2 keys it on grade.
- The School Setup wizard applies one section list to every selected grade. Use the
  per-grade Add Sections wizard for mixed structures.
- Report card v1 stays in Draft when a v2 is generated. The superseded state is only
  stamped when a published card is replaced.
